📧 Email Agent

🚀 Project Overview

An AI-powered Gmail assistant built using Google Agent Development Kit (Google ADK) and the Groq API. The agent reads Gmail messages and generates intelligent, context-aware replies on behalf of the user using the Gmail API and OAuth 2.0 authentication.

🏗️ Project Features

  • Gmail API Integration: The agent uses the Gmail API to read incoming emails and send replies.
  • OAuth 2.0 Authentication: Securely authenticates users to access their Gmail accounts.
  • Context-Aware Responses: Utilizes the Groq API to generate intelligent and contextually relevant email responses.
  • Customizable Settings: Users can configure the agent's behavior, such as response tone and frequency.

🛠️ Tech Stack

Python Google ADK Groq API Gmail API Google OAuth 2.0 Google API Python Client python-dotenv
